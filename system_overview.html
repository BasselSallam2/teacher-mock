Product journey

  1. Media Library — upload into nested folders → lesson-learner indexes file → status=indexed
  2. Chat — SSE streaming via teacher-chat; agent tools call API via MCP
  3. Plan — teacher clicks Create Lesson Plan → plan_lesson (SAQ)
  4. Slides — Approve & Execute → execute_lesson + image-manager
  5. Export — PDF / PPTX when slides_ready

Lesson status lifecycle

StatusMeaning

awaiting_plan_approvalContinue chat or create plan
planningPlan job running
awaiting_execute_approvalPlan ready — approve slides

slides_readyDone
failedError (retryable)

Critical rule: media ≠ chat

  end
  subgraph phase2 [Phase 2 — SSE then SAQ]
    ChatSSE["teacher-chat SSE"] --> Plan["planner"]
    Plan --> Exec["executer"]
  end
  Store -.-> ChatSSE

Files are indexed before chat. Chat only reads stored summaries — never re-parses uploads.
